# My mdout blog

[中文](#中文) | [English](#english)

## 中文

这是一个由 [mdout](https://github.com/labspc/mdout) 生成的独立 Markdown 博客。

```sh
mdout doctor
mdout serve
```

文章放在 `content/posts/`。发布前运行：

```sh
mdout check
mdout build
```

推送到 `main` 后，仓库自带的 GitHub Actions 会检查内容并发布到 GitHub Pages。站点设置位于 `zola.toml`，固定工具版本位于 `mdout.toml`。

## English

This is a standalone Markdown blog generated by [mdout](https://github.com/labspc/mdout).

```sh
mdout doctor
mdout serve
```

Keep articles in `content/posts/`. Before publishing, run:

```sh
mdout check
mdout build
```

Pushing to `main` runs the bundled GitHub Actions checks and deploys the site to GitHub Pages. Site settings live in `zola.toml`; pinned tool versions live in `mdout.toml`.
